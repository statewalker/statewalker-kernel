# apps

The demo applications of the platform (`notes`, `assistant`, `sandbox`), each with its own fragments and launch configurations. They are private and never published.

So far: [notes](notes), the shell tracer and the workbench chrome (the kernel with system.commands and system.workbench, a client-only notes fragment reaching its commands through menus, the palette and keybindings, a dialog and a notification, the phone, tablet and desktop modes with layouts kept per mode in system.profile, and the browser tests).

The demos are specified in statewalker/statewalker-root#215.
